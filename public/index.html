Recipe API Documentation

Welcome to the Recipe API documentation. This API provides endpoints for managing recipes, users, and related data.

Note: All API endpoints are available at /.netlify/functions/index or through the /api path.

Authentication

POST /auth/login

Authenticate a user and receive a JWT token.

Request Body:

{
  "username": "your_username",
  "password": "your_password"
}

Response:

{
  "message": "Authentication successful",
  "token": "your_jwt_token"
}

Users

POST /users

Register a new user.

Request Body:

{
  "username": "new_username",
  "firstname": "First",
  "lastname": "Last",
  "birthday": "1990-01-01",
  "email": "user@example.com",
  "phoneNumber": "1234567890",
  "password": "secure_password",
  "grade": "user",
  "status": "active"
}

Recipes

GET /recipes

Get all recipes (requires authentication).

Headers:

Authorization: Bearer your_jwt_token
